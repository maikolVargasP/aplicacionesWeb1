
# aplicacionesWeb1
El juego consiste en:
1. Mostrar cartas boca abajo que al hacer clic se volteen.
2. Al voltear dos cartas, si son iguales permanecen descubiertas; si no, deben volver a taparse.
3. El juego termina cuando todas las cartas se han encontrado.
4. El progreso de la partida debe poder retomarse en caso de cerrar el navegador.
5. Al finalizar, debe mostrar cuántos intentos se hicieron.
6. Contar el tiempo que tardó en completarse el juego.
7. Guardar el mejor tiempo o el menor número de intentos alcanzados.
8. Incluir un nivel de dificultad con más cartas.
