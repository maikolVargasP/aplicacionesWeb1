# aplicacionesWeb1
Taller práctico de desarrollo web: Ahorcado
Se quiere desarrollar una versión digital del clásico juego del ahorcado.
El juego debe:

Mostrar una palabra oculta que se adivina letra por letra.

Permitir al jugador elegir letras y mostrar si son correctas o no.

Dibujar o mostrar de manera progresiva al personaje cada vez que se falla.

El juego termina si se adivina la palabra o si el personaje se completa.

Conservar el historial de partidas para revisarlas en otro momento.

Contar el número de victorias y derrotas.

Permitir elegir diferentes categorías de palabras.

Mostrar la lista de letras ya usadas.
